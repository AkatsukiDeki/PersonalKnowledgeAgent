Он поддерживает чистоту репозитория: исключает временные и локальные артефакты (кеш, логи, настройки IDE и т. п.), которые генерируются автоматически и не должны коммититься, чтобы не вызывать лишние конфликты между разработчиками.

## Полезные лайфхаки по решению технических проблем

Если не работает буфер обмена (Ctrl+C / Ctrl+V) между Windows и Linux (Kali):

В PowerShell Windows можно отправить текст напрямую в буфер командой: Set-Clipboard -Value "текст".

В Linux (WSL) можно передавать вывод прямо в Windows-буфер через пайп: echo "текст" | clip.exe.

Перезапуск службы буфера в PowerShell: Get-Process -Name "ClipboardUserServer*" | Stop-Process -Force.

Переименование/Удаление веток:

Удаление ветки на сервере: git push origin --delete <имя_ветки>.
