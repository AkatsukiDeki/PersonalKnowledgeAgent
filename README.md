# Personal Knowledge Agent (PKA) 🧠

**Personal Knowledge Agent (PKA)** — это локально-ориентированная мультимодальная система управления личным опытом и базой знаний с графовым RAG. Архитектура отделяет веса нейросетей от структуры памяти: система векторизует документы, код, изображения и аудио, извлекает атомарные факты (*Claims*), отслеживает эволюцию решений (*Superseded Decisions*) и обеспечивает контекстный диалог через локальные (Qwen 2.5, Ollama) или облачные (Gemini) модели.

---

## 🚀 Быстрый запуск

### 1. Локальная разработка

**База данных и Бэкенд:**
```bash
# Запуск контейнеров (PostgreSQL с pgvector + Redis)
docker compose up -d

# Запуск бэкенда локально
cd backend
python -m venv venv
source venv/bin/activate  # venv\Scripts\activate для Windows
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**Фронтенд:**
```bash
cd frontend
npm install
npm run dev
```
Приложение будет доступно по адресу: `http://localhost:5173`.

### 2. Развертывание на сервере (VPS)

Для развертывания в production (включает встроенный Nginx/Frontend, Backend, Workers и базу данных в едином контуре):

```bash
cp .env.vps .env
docker compose -f docker-compose.vps.yml up -d --build
```
Приложение будет доступно по адресу `http://<IP_сервера>:8090`.

* `backend/` — Серверная часть (FastAPI, Python 3.11+, SQLAlchemy, Arq)

* `docker-compose.yml` — Инфраструктура для локальной разработки (БД + Redis)

## 🌌 Журнал обновлений (Changelog)

### v1.8.0 — Video Vision, Slide OCR & Auto-Prompting
* **Video Vision & Slide OCR (M3.4)**: Параллельный конвейер обработки видео. Извлечение уникальных кадров со сменой слайдов (через FFmpeg) и структурной дедупликацией (SSIM). Оптическое распознавание текста и кода на слайдах через `PaddleOCR`.
* **Temporal Alignment**: Умная склейка текста со слайда и аудио-дорожки лектора по таймкодам. Позволяет искать в базе фрагменты, где код был показан на экране, но не произнесен вслух.
* **Auto-Prompting Vocabulary Builder**: Автоматический сборщик лексикона для Whisper STT. Динамически вытягивает домены и имена виртуальных папок из базы данных в `initial_prompt`, обучая Whisper локальным терминам без дообучения весов модели.

### Звездная дата: Сентябрь 2026 (Стабилизация конвейера и Графовой топологии)
* **Фоновое связывание графа (Background Graph Linking):** Глобальная перелинковка сущностей (relink_durable_claims) полностью выведена из веб-воркеров (`BackgroundTasks`) и переведена на надежные фоновые задачи `Arq Cron` (выполняется каждый час). Реализованы атомарные вставки граней графа через `ON CONFLICT DO NOTHING` с дедупликацией по составным ключам, что полностью устранило утечки соединений и состояния гонки (race conditions) при параллельной обработке.
* **Стабилизация генерации диаграмм:** Внедрены жесткие системные промпты для LLM при генерации Mermaid.js графов (строгие двойные кавычки для лейблов, alphanumeric-идентификаторы), что исключило падения фронтенда при рендере дорожных карт (Roadmaps) и конспектов (Learning Studio).
* **Hardening пайплайна транскрибации:** Добавлена строгая оркестрация AI-сводки через `Semaphore(1)` для изоляции параллельных видео/аудио потоков. Встроен механизм Graceful Degradation с автоматическим каскадным переключением (Gemini Flash $\rightarrow$ локальная Ollama), обеспечивающий бесперебойную работу воркера даже при таймаутах внешнего API.
* **Устранение багов слоя БД (Generated Columns):** Успешно расследован и устранен критический баг пакетной вставки SQLAlchemy `add_all`, возникавший из-за виртуальной колонки полнотекстового поиска (`tsv`). Исключение поля из ORM-модели `Chunk` предотвратило попытки вставки не-DEFAULT значений со стороны `asyncpg`.
* **Очистка инстанса:** Убиты скрытые orphan-контейнеры старого монолитного воркера, которые "крали" задачи из очереди `pka:media` и приводили к ложным падениям пайплайна (silent failures).

### Звездная дата: Август 2026 (Этапы M3.1 / M3.2 - Media Intelligence)
* **Орбитальная сепарация:** Успешно развернута трехконтурная система фильтрации телеметрии. Радары теперь четко отличают радиовещание (подкасты и лекции) от прямых голосовых трансляций экипажа (голосовые заметки).
* **Подавление фантомных сигналов:** Устранена аномалия сенсоров `Whisper`, генерировавшая фантомные музыкальные паттерны в вакууме (тишине). Отключено зацикливание на эхо-сигналах (`condition_on_previous_text`), активированы фильтры голосовой активности (`vad_filter`) и алгоритмы зачистки радиошума (тегов типа `♪`).
* **Модернизация бортового интерфейса и связи:** Внедрены новые визуальные модули для работы с медиа: `VoiceNoteViewer`, `MediaViewer`, и `RetranscribeModal`.
* **Датчики телеметрии:** На приборную панель чата выведен радар задержек `MessageLatencyBadge`, отображающий пинг (TTFT) и время обработки генерации (TBT).
* **Калибровка систем жизнеобеспечения (БД):** Восстановлена целостность при сборке капсул `SourceResponse` и проведена синхронизация схем PostgreSQL (`NOT NULL` и `metadata_info`).

### v1.7.0 — Learning Studio v2 & Subjects Ecosystem
* **Smart Study Notes (Map-Reduce)**: Интеллектуальная генерация конспектов (Map-Reduce) по каждой отдельной теме с привязкой к конкретным векторам.
* **Subjects Ecosystem (Персистентность)**: Перенос сгенерированной дорожной карты из `Learning Studio` в полноценную дисциплину (Subject).
* **Robust Context Resolver**: Универсальная система фильтрации материалов по папкам.

### v1.6.0 — Architectural Overhaul, Audio & Virtual Folders
* **Модульная архитектура экстракции**: Внедрен `HierarchicalMapReduceExtractor` для обработки лонгридов.
* **Иерархия папок (Virtual Folders)**: Полностью виртуализированная структура папок (до 4 уровней).
* **Audio & STT Pipeline (Focus Mode)**: Поддержка загрузки и транскрибации аудио с использованием Whisper и разделением источников (Demucs).

### v1.5.0 — Engineering Optimizations & Reranking

* **Zero-Latency Embeddings**: Интегрирован асинхронный LRU-кэш на векторизацию запросов.
* **FastAPI Lifespan Warmup**: Асинхронный прогрев LLM и Embedding моделей на старте сервера.

### v1.4.1 — Security Hardening & Stabilization
* **API Security**: Внедрена строгая авторизация через `X-API-Key` и лимитирование запросов (Rate Limiting, SlowAPI).
